# CodeAlpha_CreditScoringModel

CodeAlpha Machine Learning Internship — Task 1.

## Objective
Classify customers as Good or Risky using financial-history features.

## Models
- Logistic Regression
- Random Forest

## Evaluation
Accuracy, Precision, Recall, F1-Score, ROC-AUC, confusion matrices, ROC curves and feature importance.

## Dataset
A reproducible synthetic educational dataset is generated by the program. It is not real banking data and must not be used for real lending decisions.

## Run
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python credit_scoring.py
```

Use the actual metrics produced in `outputs/model_metrics.csv`; do not invent results.
